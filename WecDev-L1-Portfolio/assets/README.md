# Assets Directory

This directory stores downloadable documents and profile media for Muhammad Shoaib's portfolio.

## Files Guide

1. **Curriculum Vitae (`Muhammad_Shoaib_CV.pdf`)**
   - Save your official resume PDF here with the exact filename: `Muhammad_Shoaib_CV.pdf`.
   - Once placed, clicking the "Download CV" button on the website will instantly download this PDF.
   - If this file is not present, the website automatically displays an informative credentials modal with a print option.

2. **Profile Photo (`profile.jpg` or `profile.png`)**
   - Place a high-resolution square headshot here named `profile.jpg` or `profile.png`.
   - The website automatically detects this file and replaces the tech monogram ("MS") with your photograph while preserving the glowing cyber ring and CGPA badge.
