# NovaTech Landing Page

## Project overview
A responsive, premium enterprise landing page for NovaTech, a fictional cloud, data and AI company. Built as a Web Development Level 1 exercise using only HTML5 and CSS3.

## Technologies
- HTML5 (semantic elements, ARIA labels, skip link)
- CSS3 (custom properties, Flexbox, Grid, media queries, `scroll-behavior`)
- Google Font: Manrope, with a system-font fallback stack
- No JavaScript, frameworks or libraries

## Features
- Sticky navigation with in-page links and a Contact button
- Hero with headline, subheadline, primary call to action ("Book a demo") and secondary link ("Explore solutions")
- Features, About, Solutions, Testimonials and Contact sections
- Testimonials clearly labelled as fictional
- Footer with navigation links and copyright
- Responsive breakpoints at 960px (tablet) and 600px (mobile); no horizontal scrolling
- Visible keyboard focus styles, accessible colour contrast, reduced-motion support
- Placeholder contact details: `hello@novatech.example` and generic social links

## Running the website
1. Download or clone the `WebDev-L1-LandingPage` folder.
2. Open `index.html` in any modern browser (double-click the file).
3. Keep `index.html` and `style.css` in the same folder.

An internet connection is needed only to load the Google Font; otherwise a system font is used.
