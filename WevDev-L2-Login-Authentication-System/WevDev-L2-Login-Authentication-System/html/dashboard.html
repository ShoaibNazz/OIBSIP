Important Architectural Security Notice: This is a client-side web development demonstration. In production environments, client-side route protection can be inspected or bypassed by users who control the browser DOM. Production systems must always execute authentication, authorization, and route protection on a secure server using slow, memory-hard key derivation functions like Argon2id or bcrypt with HttpOnly session cookies.
